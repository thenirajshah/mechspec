Keep these source notes in mind when reviewing the displayed values on the Dimension Finder.

01

Raised face

The 1.6 mm raised face is included in the thickness and length of the flange, as stated in the source reference. Do not add this height again when reading flange thickness (Q) or length through hub (Y).

02

Welding neck dimension

The marked dimension denotes the outside diameter (O.D.) of the pipe in a welding neck flange. Confirm the matching pipe schedule and wall thickness separately for fabrication.

03

ANSI B16.5 coverage

The 22″ size is marked in the source as not covered by ANSI B16.5. Check the applicable standard (or manufacturer data) before using 22″ dimensions for design or procurement.

04

Units

All flange dimensions on this site are shown in millimetres (mm). Nominal pipe size is given in inches with the corresponding NB (nominal bore) value where available.

05

Null / blank values

Some cells in the original table are blank (for example depth of socket on larger sizes). These appear as empty or “—” in the Dimension Finder and should not be assumed to be zero.

How to use the Dimension Finder

  • Select the nominal pipe size first.
  • Then choose Class 150 or Class 300.
  • Optionally filter by flange type (Welding Neck, Slip-On / Socket Weld, Lap Joint) to focus on relevant dimensions.
  • Review the result cards and cross-check critical values against the official standard or project documents.
